## 🚀 Projetos em Destaque

### 🏢 Sistema de Controle de Acesso — Condomínio Logístico
Sistema de gestão de acesso implantado em condomínio logístico que abriga centros de distribuição da **Magazine Luiza** e **Shopee**. Responsável desde a modelagem do banco até a implantação, com integração de reconhecimento facial e catracas Hikvision.
- 👥 **190 usuários ativos**
- 🚶 **1.000+ acessos de pessoas/dia**
- 🚗 **600+ acessos de veículos/dia**
- 🛠️ Stack: PHP, CakePHP, MySQL, integrações Hikvision + reconhecimento facial

### 📦 Sistema de Gestão de Inventário com RFID
Software para gestão de inventário em órgãos públicos e privados, com monitoramento de ativos móveis e imóveis via tecnologia RFID.
- 🏢 **17 clientes ativos** (mínimo 10 usuários cada)
- 📊 Contribuiu para controle patrimonial, valoração de ativos e tomada de decisão
- 🛠️ Stack: PHP, MySQL, integração RFID

### 🧩 Sistema de Inventário em .NET (Projeto Interno)
Sistema de gestão de inventário desenvolvido em **ASP.NET Core + Blazor + SQL Server**. **Projetei toda a arquitetura do zero** definição de camadas, modelagem de dados, contratos de API e fluxos de negócio e **acelerei a implementação usando ferramentas de IA como Copilot**, mantendo o controle das decisões técnicas.
- 🏛️ Arquitetura em camadas, focada em manutenibilidade e evolução
- 🤖 Uso produtivo de IA para acelerar código boilerplate, mantendo revisão e validação humana
- 🔒 Projeto privado sob NDA
- 🛠️ Stack: ASP.NET Core, Blazor, SQL Server, C#
